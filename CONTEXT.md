# Context

pixpixpix is a fast, keyboard-first image and video viewer for Linux and macOS: it puts a
picture on screen before anything else runs, and everything else is a key away.

This file holds the project's own terms. It starts empty on purpose: a term is added here
when a discussion or a decision settles what it means, not compiled up front from the code.
Until then the words are used as the [documentation](https://paxel.github.io/pixpixpix/)
uses them.

Decisions are recorded in `docs/adr/`.
