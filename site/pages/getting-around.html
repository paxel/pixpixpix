The image view is the main screen: Esc always leads back to it. From there the band, the dir column and the overview are one key away.

The key line

The bottom line of the window names the area that has the focus, which also shows a lit diode in its bottom right corner, and lists that area's keys, on as many lines as it needs. A click on a key in that line does what the key does: under the pointer the key lights up, and a click flashes it. In a pair such as Left/Right only the key a click presses lights up. ? hides the hints and brings them back, also by click.

On macOS, Cmd takes the place of Ctrl in every key on these pages.

The band

The band shows the preloaded neighbours, the current file in its middle. A hidden band comes back with b, and stays hidden across starts until then.

KeyAction
Left / Rightmove the highlight
Entershow the highlighted image
Escback to the image view, the file kept
clickshow the clicked image (also without b)

The dir column

The dir column lists the current folder among its siblings; moving through it moves the image view along. A click on a folder goes there, a double-click goes into its first subfolder, and the .. row on top goes to the parent. The key line tags what is on.

KeyAction
Up / Downgo to the folder above or below
Right / Entergo into the first subfolder
Left / Backspacego to the parent
Esc, nclose, back to the image view
.show dot files and dot folders until you leave the level
Shift+.show dot files and dot folders in every folder, until .
goverview of the current folder

The overview

A scrollable gallery of the current folder and every folder below it, with thumbnails shared with other apps through the freedesktop thumbnail cache. The dir column works the same in the overview: the overview follows the folder it goes to. What you can do to the selected file is on Turning and editing and Trash and undo.
