pixpixpix runs on Linux (x86_64 and aarch64) and macOS (Apple Silicon). Pick one way to install it; every way gives you the pixpixpix command and its short form pix3.

Homebrew on Linux

From the paxel/tap tap. Install by the full name: Homebrew then trusts just this formula from the tap, not the whole tap (see Homebrew's Tap Trust).

brew install paxel/tap/pixpixpix

It puts pixpixpix into the application menu and into "Open with" for images and videos, never as the default app. The native libraries come from your distribution.

Homebrew on macOS

The cask installs pixpixpix.app with libmpv bundled, plus the pixpixpix and pix3 commands:

brew install --cask paxel/tap/pixpixpix

The app is not signed, so macOS blocks its first start: allow it once in System Settings > Privacy & Security > "Open Anyway", or run xattr -dr com.apple.quarantine /Applications/pixpixpix.app.

Flatpak on Linux

Each release carries a Flatpak bundle for x86_64 and aarch64, with libmpv, libheif and libturbojpeg included. This installs the latest one for the current user:

curl -fsSL https://raw.githubusercontent.com/paxel/pixpixpix/summer/packaging/flatpak/install.sh | sh

It needs flatpak and curl. The script adds the Flathub remote (--user, if it is not there yet) only for the runtime, installs the bundle with --user and writes pixpixpix and pix3 commands that start the Flatpak to ~/.local/bin. Running it again updates to the latest release.

The Flatpak sees your home, /media, /run/media and /mnt. o opens files in your default apps through the desktop portal; other apps named in the settings cannot be started from the sandbox. Its settings live in ~/.var/app/io.github.paxel.pixpixpix.

To uninstall:

flatpak uninstall --user io.github.paxel.pixpixpix
rm ~/.local/bin/pixpixpix ~/.local/bin/pix3

Release tarballs

Each GitHub release carries a tarball for Linux x86_64, Linux aarch64 and macOS arm64 with the pixpixpix and pix3 binaries. Put them anywhere on your PATH. The macOS build is unsigned.

From source

With a current stable Rust toolchain:

git clone https://github.com/paxel/pixpixpix
cd pixpixpix
cargo build --release
# target/release/pixpixpix and target/release/pix3

No development packages are needed to build; the native libraries are only loaded at runtime.
