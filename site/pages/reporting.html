When something goes wrong, pixpixpix says what, and lets you copy all of it.

Copy the error

Every error has a Copy button. It copies the message together with the file, the pixpixpix version, the system and how pixpixpix was installed (Homebrew, Flatpak, the macOS app, or a release tarball or own build), ready to paste into a search or a bug report.

A missing library is the most common cause; the error names it, and Formats and libraries lists the package to install on your system.

File an issue

Open an issue on GitHub and paste the copied text. Say what you did and what you expected instead.
